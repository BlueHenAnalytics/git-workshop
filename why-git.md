## Why use Git in the first place?
Git is essentially just a glorified Google Drive - so why use it?
**Your repositories can be public**
- You can showcase your projects for employers, peers, and friends
**Industry Standard**
- Everybody remotely involved in tech uses it, and you should too
**Feature Density**
- Git has a ton of features, such as branches and forks, which make it easy to collaborate
**Finding Software**
- You can find some pretty cool software on GitHub, such as flowchart makers, text editors, and more!
