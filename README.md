#### What is a README.md?
- Central point of information about your repository*
- Insight into what your project is
- Collaborators, language(s), method(s), images, etc.

#### *What is a repository?
- Digital storage space that holds information
What information?
- Files
- Versions of those files
- Branches of files ("forking" code)
